How Settings Work
  • Failed Login Threshold: If an IP has this many failures in the time window → HIGH alert.
  • Time Window: The sliding time window (minutes) for counting events.
  • Normal Login Hours: Successful logins outside these hours → MEDIUM alert.
  • Multi-Username Threshold: This many different usernames from one IP → MEDIUM alert.
  • Server Failure Threshold: This many offline checks → HIGH repeated-failure alert.
